# SchemaWise AI - Complete Project

You do not need to create any source files.

## Run on Windows

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `START_PROJECT.bat`.
4. Wait until the terminal shows that Uvicorn is running.
5. Open `http://127.0.0.1:8000` in Chrome.

## Technologies included

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- SQLite

## Features included

- SQL input
- 5 sample schemas
- Schema validation
- Primary-key checking
- Foreign-key checking
- Naming checks
- Constraint suggestions
- Index suggestions
- Schema score
- Table visualization
- Relationship visualization
- Step-by-step review animation
- Explanation panel
- Review history using SQLite
- Downloadable report
- Responsive UI
- Dark/light mode
- Test cases
- AI usage log
- User manual

The app works fully offline after Python packages are installed.

# USER MANUAL

1. Run START_PROJECT.bat.
2. Open http://127.0.0.1:8000
3. Paste CREATE TABLE SQL or click Sample 1-5.
4. Click Review Schema.
5. Read score, errors, warnings, suggestions, visualization, and explanation.
6. Click History to view older reviews.
7. Click Download Report to save the result.
8. Use Dark/Light button to switch theme.

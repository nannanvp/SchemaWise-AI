# SchemaWise AI

A DBMS learning app with SQL schema review, a schema designer, official GATE past-year questions, and optional Groq AI tutoring and practice generation. FastAPI serves the frontend and API from one service.

## Run locally (Windows)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
Copy-Item backend/.env.example backend/.env
# Edit backend/.env and enter GROQ_API_KEY for AI features.
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

Open http://127.0.0.1:8001. START_PROJECT.bat also installs dependencies and starts the app. Python 3.11 is supported.

## Question sources

Quiz offers two explicit modes:
- **Official GATE PYQs:** 96 questions rendered from the supplied ExamSIDE PDFs and graded against their supplied answer keys. ER Diagrams: 16; File Structures and Indexing: 20; Functional Dependencies and Normalization: 20; Relational Algebra: 20; Transactions and Concurrency: 20.
- **AI-generated practice:** up to 10 new DBMS multiple-choice questions per request, generated by Groq with answers and explanations. Generated content is labelled AI practice, can contain mistakes, and is never added to the official bank. Requires a working server-side API key. A provider failure reports an error rather than inventing an official source.

Exam Questions contains only the sourced bank. Learn, Download, and Help each have a separate sidebar panel. The original PDFs are linked beside the question images. Existing crop limitations remain: some images may omit edge text or include extra whitespace; consult the original PDF when needed. Crops were preserved pending user approval.

Question images and PDFs remain third-party source material; no authorship or blanket license is claimed over them. Source metadata is in frontend/gate/sources.json.

## Deploy both repositories

Follow [the Render and professor submission guide](docs/DEPLOYMENT.md). Both repositories use the same application code and independent Render services. The copy has its own service and display names.

Never put a real Groq key into a committed file. Use Render environment variables or a local ignored backend/.env. AI availability on the status chip indicates configuration, not a completed provider request; generate a practice question to check the full connection.

## Storage and limits

SQLite stores review history and quiz scores. Render Free storage is ephemeral: these records reset on restart, redeploy, or idle spin-down. The bundled question bank is redeployed from Git and remains available. Use a paid persistent disk with SCHEMAWISE_DB=/data/history.db when durable history is required. Quiz scores are a learning aid, not a secure examination system.
